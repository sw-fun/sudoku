Cell keypad popup from user feedback: tapping an empty/player cell opens a phone-style 3x4 mini keypad (digits 1-9 + Erase) anchored beside the cell toward the board center so it never leaves the board or obscures the target; tapping the selected cell again toggles it closed/re-open. Context rules: no popup for givens, notes mode, show-me, or won; Erase disabled on empty cells; the digit matching a red wrong value disabled (red numbers are directly replaceable); completed digits disabled as in the main pad; any placement/erase closes the popup.
